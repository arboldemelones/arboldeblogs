## Cómo

La web está hecha con el framework [Hugo](https://gohugo.io) y he modificado el tema [Notrack](https://github.com/gevhaz/hugo-theme-notrack), copiándole el estilo descaradamente a [lagomor.ph](https://lagomor.ph), un saludo si lo ves y traduces este texto.

La mayor fuente de inspiración para el estilo es que me gustan los píxeles y el [dithering con filtro de Bayer](https://en.wikipedia.org/wiki/Ordered_dithering).

El fondo es [este video de nubes](https://youtu.be/E-AMIs2iXBo) habiéndole aplicado dithering utilizando este [tutorial de After Effects](https://youtu.be/3XlO5J7XorI).

Las tipografías son: 
 - TeX Gyre Pagella para el texto general
 - `IBM Plex Mono para el texto monoespaciado y los títulos`
 - {{< rawhtml >}}<span style="font-family: FsJenson, serif; font-size: 1.6em"><a style="font-family: FsJenson, serif;" href="https://fontstruct.com/fontstructions/show/991872/fs_jenson_1">fs jenson 1</a> para el encabezado de la pagina</span>{{< /rawhtml >}}

Mi [robots.txt](/robots.txt) no permite buscar este blog (se supone), así que gracias por entrar!
